# openEuler Desktop 适配项目

项目旨在将深度桌面（Deepin/Deepin Desktop Environment）相关体验与组件适配到 openEuler 发行版上，提供配置、打包、兼容性修复与调试指南，帮助开发者和系统维护者在 openEuler 上部署更一致、更流畅的桌面体验。

**主要目标**
- 在 openEuler 上构建并发布可用的桌面环境组件包（主题、图形驱动、窗口管理、系统服务等）。
- 修复与上游桌面环境在 openEuler 平台上的兼容性问题（依赖、系统调用、SELinux/安全策略等）。
- 提供一套可重复的构建与打包流程，便于测试与发布。

**适配范围（示例）**
- 桌面组件：窗口管理器、任务栏、控制中心、设置面板、通知等。
- UI 资源：主题、图标、字体与本地化资源（简体中文）。
- 系统集成：会话管理、启动项、系统服务、驱动与硬件加速支持。

**仓库结构（示例）**
- `docs/`：适配说明与设计文档。
- `scripts/`：构建、打包与安装脚本。
- `patches/`：针对上游源代码的补丁合集。
- `packages/`：生成的二进制包与打包脚本。

如果当前仓库尚未包含这些目录，可以根据需要创建并补充对应内容。

**快速开始（建议）**
1. 克隆仓库：

	git clone https://github.com/jiekie886/openeuler-desktop.git
	cd openeuler-desktop

2. 阅读 `docs/`（如果存在）获取针对具体 openEuler 版本的适配说明与先决条件。
3. 若仓库含 `scripts/build.sh` 或类似构建脚本，先安装脚本中列出的依赖，再运行构建脚本。
4. 本地测试时，建议在虚拟机或容器中验证桌面会话与基本功能（显示、窗口、输入法、多媒体）。

**构建与打包（通用建议）**
- 明确目标 openEuler 版本与包管理格式（RPM）。
- 使用可重复的构建环境（如 chroot、mock、podman/buildah 或 CI runner）。
- 将针对上游的补丁集中放在 `patches/` 并在构建脚本中自动应用。
- 为关键组件准备单元测试或集成测试脚本，方便回归验证。

**调试与常见问题**
- 显示相关问题：检查图形驱动、X/Wayland 日志、合成器配置。
- 启动/会话问题：观察 systemd、用户会话日志以及 DBus 交互。
- 权限/安全策略：根据需要为服务添加 SELinux 策略或调整 polkit 规则（谨慎操作并记录变更）。
